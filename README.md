# 선택지 번역기

메시지 속 `<choices>` 같은 태그나 드래그한 글만 골라 번역해서 **팝업으로** 보여주는 SillyTavern 확장입니다.

메시지 화면은 그대로 두기 때문에, 메시지 전체를 번역하는 다른 확장과 함께 써도 서로 부딪히지 않습니다.

예를 들어 메시지에 이런 부분이 있으면

```
<choices>
1. Follow her into the alley
2. Call out her name
</choices>
```

버튼 한 번으로 이 부분만 번역해 팝업에 띄워 줍니다.

```
1. 그녀를 따라 골목으로 들어간다
2. 그녀의 이름을 부른다
```

## 설치

1. 실리태번 위쪽의 확장(블록 아이콘) 메뉴를 엽니다.
2. **Install extension**을 누르고 아래 주소를 붙여 넣습니다.
   ```
   https://github.com/canclank/SillyTavern-ChoiceTranslator
   ```
3. 설치가 끝나면 확장 설정에 **선택지 번역기** 항목이 생깁니다.

요구 버전: SillyTavern 1.12.14 이상

업데이트는 확장 관리 화면의 업데이트 버튼으로 받을 수 있습니다.

## 처음 설정

1. **번역할 태그**: 기본값은 `choices`입니다. 다른 태그를 쓰는 카드라면 그 이름으로 바꿔 주세요.
2. **연결 프로필**: 번역에 쓸 모델을 고릅니다. 비워 두면 지금 채팅에 쓰는 API로 번역합니다.
3. **연결 테스트**: 버튼을 눌러 번역 모델이 응답하는지 확인합니다.

연결 프로필은 실리태번의 API 연결 패널에서 만든 Connection Manager 프로필입니다. 번역용으로 프로필을 따로 골라도 채팅 중인 연결은 바뀌지 않습니다.

## 기능

### 선택지 번역
태그가 들어 있는 부분만 꺼내 번역해 팝업으로 보여줍니다. 아래 세 곳 중 편한 곳에서 누르면 됩니다.

- 태그가 있는 메시지에 생기는 ☑ 버튼
- 화면 오른쪽 아래의 플로팅 버튼
- 마법봉 메뉴의 **선택지 번역**

팝업 윗줄을 누르면 내용이 접히고, 다시 누르면 펼쳐집니다. 답장을 쓰는 동안 접어 두면 화면을 덜 가립니다.

번역 중에는 팝업에 **중단** 버튼이 나옵니다. 누르면 그 자리에서 번역을 멈추고, 팝업의 **다시 번역**으로 처음부터 다시 할 수 있습니다. 연결 프로필을 쓰면 요청 자체가 끊기고, 메인 API로 번역할 때는 결과만 버립니다(요청은 뒤에서 끝까지 진행될 수 있어요).

플로팅 버튼이나 마법봉으로 번역하면 화면에 보이는 메시지 중 가장 아래쪽 선택지를 번역합니다. 화면에 선택지가 없으면 가장 최근 선택지를 번역합니다.

### 다른 태그도 번역
`choices` 말고도 원하는 태그를 얼마든지 넣을 수 있습니다. 설정의 **번역할 태그** 칸에 한 줄에 하나씩 적으면 됩니다.

```
choices
status
options
div.choices
```

- **태그 이름** (`status` 등): 메시지 원문에서 `<태그>…</태그>`로 열고 닫힌 부분을 찾습니다.
- **CSS 선택자** (`div.choices` 등): 화면에 보이는 요소의 글자를 읽습니다.
- 한 메시지에 여러 태그가 있으면 팝업에 나눠서 보여줍니다.

### 자동 번역
설정의 **새 AI 메시지가 오면**에서 고를 수 있습니다.

| 선택 | 동작 |
|---|---|
| 아무것도 하지 않기 | 버튼을 누를 때만 번역합니다. |
| 미리 번역해 두기 | 백그라운드에서 번역해 두고, 버튼을 누르면 바로 보여줍니다. |
| 번역해서 팝업 바로 띄우기 | 새 메시지가 오면 팝업을 바로 띄웁니다. |

### 드래그 번역
채팅에서 글을 드래그하면 번역 버튼이 뜹니다. PC에서는 선택한 글 옆에, 모바일에서는 입력창 위 가운데에 뜹니다.

### 플로팅 버튼

| 버튼 | 동작 |
|---|---|
| ≡ 손잡이 | 끌어서 위치를 옮깁니다. |
| ▲ / ▼ | 이전/다음 메시지로 이동합니다. 길게 누르면 맨 위/맨 아래로 갑니다. |
| ☑ | 선택지를 번역합니다. |

### 프롬프트
번역에 쓰는 시스템 프롬프트와 번역 프롬프트를 직접 고칠 수 있습니다.

- `{{text}}`: 번역할 원문
- `{{language}}`: 목표 언어
- `{{char}}`, `{{user}}` 같은 실리태번 매크로도 쓸 수 있습니다.

설정의 **번역 테스트**로 지금 프롬프트가 어떻게 번역하는지 예문으로 확인할 수 있습니다.

## 원하는 기능만 쓰기
모든 기능은 설정에서 따로 켜고 끌 수 있습니다.

| 기능 | 설정 위치 |
|---|---|
| 메시지의 ☑ 버튼 | 선택지 번역 → 태그가 있는 메시지에 번역 버튼 표시 |
| 마법봉 메뉴 | 선택지 번역 → 마법봉 메뉴에 "선택지 번역" 표시 |
| 자동 번역 | 선택지 번역 → 새 AI 메시지가 오면 |
| 드래그 번역 | 드래그 번역 → 텍스트를 드래그하면 번역 버튼 표시 |
| 플로팅 버튼 전체 | 플로팅 버튼 → 화면에 플로팅 버튼 띄우기 |
| 플로팅 번역 버튼 / ▲▼ 버튼 | 플로팅 버튼 → 각각 따로 |

## 번역 저장
**번역 결과 저장**이 켜져 있으면(기본값), 한 번 번역한 결과를 저장해 두고 같은 내용은 다시 요청하지 않습니다.

- 선택지 번역 결과는 채팅 파일에 저장되어, 채팅을 다시 열어도 유지됩니다.
- 팝업의 **다시 번역**을 누르면 저장된 결과를 무시하고 새로 번역합니다.
- 목표 언어, 프롬프트, 연결 프로필을 바꾸면 자동으로 새로 번역합니다.
- 설정의 **이 채팅의 저장된 번역 지우기**로 저장된 결과를 지울 수 있습니다.

## 문제가 있을 때

| 증상 | 해결 |
|---|---|
| 번역이 안 됨 | 설정의 **연결 테스트**로 모델이 응답하는지 확인하세요. 오류 내용이 그대로 표시됩니다. |
| 응답이 비어 있음 | 추론(Thinking) 모델이라면 **최대 응답 토큰**을 늘려 보세요. |
| ☑ 버튼이 안 보임 | 아래 "태그를 인식하지 못할 때"를 확인하세요. 버튼은 태그가 있는 메시지에만 나타납니다. |
| 플로팅 버튼이 안 보임 | 설정의 **안 보일 때 진단** 버튼을 누르면 원인이 표시됩니다. |

### 태그를 인식하지 못할 때
확장은 화면에 보이는 모습이 아니라 **메시지 원문**에서 태그를 찾습니다. 메시지의 편집(연필) 버튼을 눌러 원문을 확인해 보세요.

- **이름이 다름**: 원문은 `<choice>`인데 설정에는 `choices`로 적혀 있는 경우처럼 한 글자라도 다르면 찾지 못합니다. 대소문자는 상관없습니다.
- **원문에는 태그가 없음**: 정규식(Regex) 스크립트가 화면에 보일 때만 태그나 꾸밈을 만들어 내는 카드가 있습니다. 이때는 원문에 실제로 적힌 표시(예: `[선택지]`)를 쓰는 대신, 화면에 그려진 요소를 `div.choices` 같은 CSS 선택자로 지정하세요.
- **생각(추론) 영역 안에 있음**: 모델이 선택지를 추론 블록 안에 써 버린 경우에는 본문이 아니라서 찾지 못합니다.

닫는 태그가 빠졌거나 응답이 중간에 잘린 경우는 자동으로 처리합니다. 이때는 여는 태그부터 메시지 끝까지를 번역합니다.

## 슬래시 커맨드

```
/sttr 텍스트          텍스트를 번역해 결과를 반환
/sttr-tags            마지막 메시지의 선택지 번역 팝업
/sttr-tags 12         12번 메시지의 선택지 번역 팝업
/sttr-stop            진행 중인 모든 번역 중단
/sttr-debug           플로팅 버튼 진단
```

예: `/sttr Hello there | /echo`
