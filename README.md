# 선택지 번역기 (실리태번 확장)

메시지 안의 `<choices>` 같은 특정 태그 내용이나 드래그한 텍스트만 골라 번역해서 **팝업으로** 보여주는 SillyTavern 확장입니다. 플로팅 버튼으로 메시지 단위 이동도 할 수 있습니다.

메시지 화면은 전혀 수정하지 않습니다. 그래서 메시지 전체를 번역하는 다른 확장과 함께 써도 충돌하지 않습니다.

## 설치

**직접 복사**

폴더 이름을 반드시 영문 `SillyTavern-ChoiceTranslator`로 해서 아래 위치 중 하나에 넣고, 실리태번을 새로고침합니다.
- 현재 사용자만: `SillyTavern/data/default-user/extensions/SillyTavern-ChoiceTranslator/`
- 모든 사용자: `SillyTavern/public/scripts/extensions/third-party/SillyTavern-ChoiceTranslator/`

> 폴더 이름에 한글을 쓰면 압축을 풀거나 옮기는 과정에서 이름이 깨질 수 있습니다. 깨진 폴더는 실리태번의 삭제 버튼으로도 지워지지 않으니 영문 이름을 쓰세요.

**이전 버전(`st-translator`)에서 업데이트할 때**

기존 `st-translator` 폴더를 반드시 지워 주세요. 두 폴더가 모두 남아 있으면 확장이 두 번 로드됩니다. 설정값은 그대로 이어집니다.

요구 버전: SillyTavern 1.12.14 이상.

## 기능

각 기능은 설정에서 따로 켜고 끌 수 있습니다.

| 기능 | 설정 위치 |
|---|---|
| 메시지 버튼으로 선택지 번역 | 선택지 번역 → 태그가 있는 메시지에 번역 버튼 표시 |
| 새 메시지 자동 번역 | 선택지 번역 → 새 AI 메시지가 오면 |
| 드래그 번역 | 드래그 번역 → 텍스트를 드래그하면 번역 버튼 표시 |
| 플로팅 막대 전체 | 플로팅 버튼 → 화면에 플로팅 버튼 띄우기 |
| 플로팅 막대의 번역 버튼 / ▲▼ 이동 버튼 | 플로팅 버튼 → 각각 따로 |
| 마법봉 메뉴의 "선택지 번역" | 선택지 번역 → 마법봉 메뉴에 "선택지 번역" 표시 |

### 선택지 번역
원본 메시지에서 `<choices>…</choices>` 안쪽만 꺼내 번역합니다. 결과는 팝업으로 보여줍니다.
- 팝업 윗줄을 누르면 내용이 접히고, 다시 누르면 펼쳐집니다.
- 플로팅 막대나 마법봉에서 번역할 때는, 화면에 보이는 메시지 중 가장 아래쪽 선택지를 번역합니다. 화면에 선택지가 없으면 가장 최근 선택지를 번역합니다.

### 플로팅 막대
| 버튼 | 동작 |
|---|---|
| ≡ 손잡이 | 끌어서 위치를 옮깁니다. |
| ▲ / ▼ | 이전/다음 메시지로 이동합니다. 길게 누르면 맨 위/맨 아래로 갑니다. |
| ☑ | 선택지를 번역합니다. |

### 드래그 번역
텍스트를 드래그하면 번역 버튼이 뜹니다.
- PC에서는 선택한 텍스트 옆에 뜹니다.
- 모바일에서는 기본 선택 메뉴와 겹치지 않도록 입력창 위 가운데에 뜹니다.

### 연결 테스트
연결 프로필 옆의 **연결 테스트** 버튼을 누르면, 선택한 프로필로 아주 짧은 요청을 보냅니다. 결과에 응답 여부, 걸린 시간, 응답 내용이 나옵니다.

**번역 테스트**는 이와 달리 지금 설정한 프롬프트로 예문을 실제로 번역해 봅니다.

## 번역 저장(캐시)
"번역 결과 저장"이 켜져 있으면(기본값) 아래처럼 동작합니다.
- **선택지 번역:** 결과가 채팅 파일의 메시지 정보에 저장됩니다. 같은 메시지는 다시 열어도 API를 부르지 않습니다. 채팅을 다시 열어도 유지됩니다.
- **드래그 번역:** 새로고침 전까지 메모리에 최대 200개까지 기억합니다.
- **새로 번역하기:** 팝업의 "다시 번역" 버튼은 저장된 결과를 무시하고 새로 번역합니다.
- **자동 무효화:** 목표 언어, 프롬프트, 프로필이 바뀌면 이전 결과는 쓰지 않고 새로 번역합니다.

## 슬래시 커맨드
```
/sttr Hello there | /echo     텍스트 번역
/sttr-tags                     마지막 메시지의 선택지 번역 팝업
/sttr-tags 12                  12번 메시지의 선택지 번역 팝업
/sttr-debug                    플로팅 버튼이 안 보일 때 진단
```
